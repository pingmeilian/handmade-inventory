## 怎么换成本机真机截图

1. 微信开发者工具 → 控制台执行 `require('tools/demo.js').fillDemoData()`
   （灌**演示数据**：客户名是假的，别用真实账目截图）
2. 模拟器切到 iPhone 尺寸，页面滚到目标位置，关掉调试栏，截图
3. 按**同名覆盖**本目录里的文件即可，README 无需改动
